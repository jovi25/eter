# Arte por IA — guia de pedidos

O jogador gera as ilustrações numa IA de imagem gratuita, e o Claude escreve os textos (prompts) usados.
O Claude recorta o fundo, coloca as imagens no jogo e anima tudo por código: respiração, bote de ataque,
projéteis, partículas e brilho.

## Regras para toda imagem

1. **Fundo magenta liso (#FF00FF).** É a cor que o Claude remove. Não aceite fundo xadrez "falso transparente".
2. **De lado, olhando para a direita, corpo inteiro.** Nada cortado e sem chão desenhado.
3. **Sem partículas soltas** (faíscas, folhas voando) e sem textos ou setas. Os efeitos vêm do jogo.
4. **Mantenha a mesma conversa** para as imagens de uma mesma linha, para a IA manter o desenho igual.
5. **Use a tabela de dragões como referência.** Anexe a imagem que você já fez e peça para usar a linha do elemento.
6. **Envie o arquivo original** baixado da IA, não um print da tela.

## Bloco de estilo (vai dentro de todos os pedidos de criatura)

```
Style: polished professional 2D game illustration, cute chibi proportions, soft cel shading with gentle gradients, clean dark-brown outline, expressive eyes of natural size (not bulging), warm saturated colors, light coming from the top left. Same art style, line weight and colors for all creatures.
```

## Piloto (fase atual)

### 1. Fogo — parado
```
Use the "Fogo" row of the attached image as the design reference.

Wide landscape image (3:2). Character sheet for a mobile tower defense game: the 3 evolution stages of the same cute fire dragon, side by side from left to right (stage 1, stage 2, stage 3), with wide empty space between them, all standing on the same invisible ground line, all facing right in a 3/4 side view, calm idle pose, full body visible, nothing cut off.

Stage 1: tiny round baby dragon on four short legs, big head, stubby wing buds, small flame on the tail tip, cheerful.
Stage 2: young dragon, slimmer and taller, small wings, two little horns, a bandage on one front leg, flame on the tail tip.
Stage 3: confident adult dragon with bronze shoulder armor, bigger horns and a flaming mane; wings raised UP and folded close to the body (not spread wide), so the silhouette stays compact, about as wide as it is tall.

Style: polished professional 2D game illustration, cute chibi proportions, soft cel shading with gentle gradients, clean dark-brown outline, expressive eyes of natural size (not bulging), warm saturated colors, light coming from the top left. Same art style, line weight and colors for all three.

Background: one solid flat magenta color (#FF00FF) filling everything. No gradient, no ground, no shadow, no scenery, no floating sparks or particles, no text, no arrows, no labels.
```

Same style and same background: one solid flat magenta color (#FF00FF). No gradient, no ground, no shadow, no floating sparks or particles, no text.
